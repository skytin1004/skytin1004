# Hi, I'm Minseok Song

I build AI workflows and teach teams how to use them. My work spans Power Platform automation, Azure AI, and the details that help a system keep working: documentation, failure handling, and human review.

I'm a [Microsoft MVP in Microsoft Foundry](https://mvp.microsoft.com/mvp/profile/78bed86f-8f4b-41f9-ba0c-b707ec42e08c), founder of [Reliable Workflow](https://reliableworkflow.com/) and [Localizeflow](https://localizeflow.com/), and an open-source maintainer.

[Training and workshops](https://www.mssong.com/services/#programs) · [Discuss an automation project](https://reliableworkflow.com/#contact) · [LinkedIn](https://www.linkedin.com/in/ms-song/)

## Projects

- **[Localizeflow](https://localizeflow.com/)** — A service I founded to keep repository documentation translated and deliver changes through reviewable pull requests. [See a completed translation run](https://app.localizeflow.com/status/Jw1ms2q86a), including its execution record and the pull request delivered for review.
- **[Agents Decide, Containers Execute](https://github.com/skytin1004/agents-decide-containers-execute)** — A sample where a Microsoft Foundry agent selects approved documentation checks and Azure Container Apps Jobs execute them. [See the recorded result](https://github.com/skytin1004/agents-decide-containers-execute/issues/1).
- **[AI-assisted support intake](https://github.com/skytin1004/ai-assisted-support-intake)** — An Azure Functions classifier and Power Platform custom connector for a Power Automate support workflow with human approval.

## Teaching

I teach Power Platform automation and Azure AI through practical workshops. I like to start with a business problem, understand the manual work and its constraints, and then choose the tools that fit.
